# Glossar FR → DE (Kosmische Ereignisse)

## Grundsätze
- Anrede: **du** (klein). Zahlen: 384.400 km, 0,53°, 40 %. Anführungszeichen „…“.
- Dauer-/Entfernungsbausteine (`{0} Tage`, `{0} Jahre`, `{0} Lichtjahre` …) stehen im Nominativ/Akkusativ; Sätze mit Platzhalter sind so gebaut, dass kein Dativ nötig ist (`Dans {0}` → `{0} ab heute`, `arrive dans {0}` → `noch {0} bis …`, `Un tour en {0}` → `Ein Umlauf dauert {0}`).
- Tasten: ZQSD → WASD, Maj → Shift, Espace → Leertaste, Échap → Esc, molette → Mausrad, clic droit → Rechtsklick, glisser → ziehen.
