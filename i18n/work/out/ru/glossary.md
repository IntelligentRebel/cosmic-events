# Glossaire ru (Cosmic Events)

- Theia, la naissance de la Lune → Тейя: рождение Луны (Theia = Тейя, féminin)
- La forge de l’or → Кузница золота

- Le matin de Tcheliabinsk → Челябинское утро; lac Tchebarkoul → озеро Чебаркуль

- Voie lactée contre Andromède → Млечный Путь против Андромеды
- La mort du Soleil → Смерть Солнца
- L’anneau de Mars → Кольцо Марса; Phobos → Фобос (masculin, «спутник»)
- Cygnus X-1 → Лебедь X-1
- L’étoile déchiquetée → Разорванная звезда
- Tomber dans un trou noir → Падение в чёрную дыру
- Sagittarius A* → Стрелец A*; M87*; Fermi → «Ферми»; Hubble → «Хаббл»; Galileo → «Галилео»; LIGO, Virgo, NASA en latin
- Yucatán → Юкатан; plate-forme du Yucatán → Юкатанская платформа; océan des Tempêtes → Океан Бурь
- Grand Nuage de Magellan → Большое Магелланово Облако; galaxie du Triangle → галактика Треугольника

## Unités (formes valables après un nombre décimal)
- UA → а. е.; a.-l. / années-lumière → св. лет; km → км; m → м; cm → см; K → К; Hz → Гц; km/s → км/с
- jours → сут; h → ч; min → мин; s → с; ms → мс; µs → мкс; mois → мес.; ans → лет
- milliers d’années → тыс. лет; millions d’années / Ma → млн лет; milliards d’années / Ga → млрд лет
- tours par seconde → об/с; «N fois X» avec placeholder → «N × X» (évite раз/раза)
- rayons (après décimal) → радиуса
- Dans {0} → Через {0}; Aujourd’hui + {0} → Сегодня + {0}; T − {0} / T + {0} inchangés
- Nombres : virgule décimale, milliers séparés par une espace insécable à partir de 5 chiffres (10 000 ; 3600)
